# PRIME DRIVE — React + Vite

Переработка Angular-проекта аренды автомобилей в React. Сохранены оригинальные изображения автомобилей из предоставленного архива.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Сборка

```bash
npm run build
npm run preview
```

## Улучшения
- Новый адаптивный дизайн и мобильное меню
- Каталог с поиском, фильтрацией по маркам и сортировкой
- Избранные автомобили (в пределах текущей сессии)
- Выбор машины автоматически заполняет форму бронирования
- Валидация имени, телефона и автомобиля
- Семантические элементы, alt-тексты, SEO-метаданные
- Устранена ошибка исходной Angular-формы: кнопка была отключена при корректном заполнении
- Исправлены неверные подписи характеристик: объём двигателя теперь указан в литрах

**Важно:** это фронтенд-демонстрация. Заявки **не отправляются** на сервер и не сохраняются; интерфейс честно предупреждает об этом. Для реальных заказов подключите backend/Telegram и добавьте политику обработки персональных данных. Название PRIME DRIVE — демонстрационный бренд, не связано с реальным арендодателем. Условия аренды и наличие автомобилей не подтверждены.
